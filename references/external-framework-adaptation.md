# 外部拆解框架适配与评分

当用户要求按照一份飞书、Notion、Wiki、文档、课程模板或既有报告结构重做拆解时读取本参考。

## 1. 外部框架的身份

外部框架属于方法来源 `M##`，它可以决定：

- 报告章节顺序；
- 需要回答的问题；
- 表格、画布和图表类型；
- 评分维度和表达风格；
- 示例产品的分析深度。

它不能自动证明目标产品的任何事实。示例中的市场数字、Agent 名称、模型、工具、Prompt、分数和架构都不能迁移到目标产品。

## 2. 只读获取流程

1. 优先使用对应工作区的官方连接器或 CLI，以用户身份和最小只读权限读取。
2. 先取节点元数据和大纲，再取全文或相关章节；记录标题、对象类型、修订号和访问日期。
3. 如缺少权限，只请求错误明确指出的只读 scope；不要猜测或一次申请宽权限。
4. 授权等待期间不得用搜索摘要、缓存片段或旧截图冒充全文。
5. 不把设备码、二维码地址、用户 open ID、token 或 secret 写入报告或日志摘要。
6. 若始终无法访问，说明限制并要求用户导出内容；只有用户明确接受时才按可见片段做部分适配。

## 3. 先抽取框架，再写目标产品

对外部框架建立结构表：

| 框架章节 | 它要求回答的问题 | 需要的最低证据 | 目标产品证据状态 | 对应报告位置 |
|---|---|---|---|---|

特别检查：

- 是否包含体验测试和固定场景；
- 是否要求市场、商业、竞品或定价；
- 是否把 Workflow 阶段直接命名成 Agent；
- 是否要求全局上下文、工具、Prompt 或模型路由；
- 是否要求打分；
- 是否缺少证据索引、数据层、失败路径、As-Is/To-Be 或完成验证。

采用外部章节顺序时，本 Skill 的缺失项可嵌入最接近的章节或附录，但不能删除。

## 4. 映射规则

### 保留

- 用户明确要求的章节名称和叙事顺序；
- 能显著提升理解的表格与图表；
- 适用于目标产品的通用分析问题。

### 改写

- 把示例行业语言改成目标产品的任务语言；
- 把示例角色名改写为证据中可见的角色或职责单元；
- 把固定模型/工具列表改成“可确认 / 合理推断 / 尚未确认”；
- 把单一完成信号改写成完成矩阵。

### 拒绝继承

- 示例产品分数；
- 未核验市场规模和厂商排名；
- 推导出来的 Prompt 当作官方 Prompt；
- 官方 Multi-Agent 描述当作当前运行证明；
- 把产物存在当作内容正确或任务完成；
- 从页面风格、文件名或阶段名推断后端技术栈。

## 5. 市场、商业和竞品部分

这些信息会随时间变化：

- 当前定价、套餐、credits、并发与额度；
- 产品功能、模型名称、团队和企业能力；
- 法律、合规、认证和数据政策；
- 公司规模、营收、用户量和市场排名；
- 竞品能力与价格。

必须在分析时访问当前一手来源。优先顺序：官方产品/帮助中心/文档/监管文件/原始研究；厂商自报数字明确标记归属和未审计状态。生成报告中的链接只能作为待核验线索，不能因链接存在就升级为 `O##`。

如果可靠市场规模证据不存在，保留“市场层”结构并明确不填 TAM、份额或排名，不用二手估计补齐版面。

## 6. 评分协议

### 评分前提

每个维度必须公开：

- 维度定义；
- 权重或满分；
- 观察样本；
- 最低证据门槛；
- 对应 `E/O/A/C/G` 编号；
- 分析者评分还是产品自报指标。

### 证据不足的处理

- 达到门槛：可以评分，并说明扣分理由。
- 部分达到：可缩小维度或标注低置信度，不得假装完整覆盖。
- 未达到：写“未评分”，保留其满分值。
- 未观察失败样本：失败恢复、稳定性、退款、幂等通常不得评分。
- 只有官方能力说明、没有运行证据：可评价“能力声明完整度”，不能评价“实际运行表现”。

### 展示格式

推荐：

```text
可观察项：58 / 80
未评分：20（Multi-Agent 实际运行 10；失败/计费/降级 10）
不归一为 72.5 / 100
```

不得：

- 把未知项按 0 分后称为产品总分；
- 删除未知项并自动折算成 100 分；
- 用单次成功任务评价稳定性；
- 把主观打分写成行业基准；
- 没有对照实验时给出“提升 X%”。

### 评级

如果外部框架要求 90–100、70–89 等评级区间，可以保留评级规则，但只有可评分覆盖达到完整门槛时才把产品放入区间。否则显示“本次不评级”以及缺失证据。

## 7. 外部框架适配完成检查

- 外部框架已标为 `M##`，没有混入产品证据；
- 框架章节和 Skill 必需项都有映射；
- 示例产品事实、Agent、模型和分数没有迁移；
- 时间敏感事实已核对当前一手来源；
- 不支持的结构位保留为未知并列出补证；
- 评分显示可评分分母和未评分项；
- 报告说明“按该框架组织”不等于“复刻该报告结论”。
